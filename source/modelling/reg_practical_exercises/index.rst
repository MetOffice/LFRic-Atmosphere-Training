************************************
Exercises in Regional Configurations
************************************

The aim of this practical is to gain hands-on experience in running and
analysing limited-area (regional) configurations.

.. admonition:: In this module you will learn about...

   * the structure of a regional nesting suite and the roles of the driving
     model and nested limited-area model
   * copying a regional workflow and configuring its run, cycling, and
     post-processing options
   * defining a nested domain, its resolution, ancillary data, and science
     configuration
   * running a regional workflow with Cylc and monitoring its progress
   * locating, inspecting, and visualising regional model output

.. admonition:: At the end of this module you should be able to...

   * copy an existing regional nesting suite to create an editable experiment
   * use the Rose GUI to configure the site, project, cycle times, driving
     model, and post-processing options for a regional run
   * define a nested limited-area domain and select its horizontal and vertical
     resolution, ancillary data, and science configuration
   * start and monitor a regional Cylc workflow
   * locate and inspect the resulting NetCDF files and create visualisations
     using an appropriate analysis tool
